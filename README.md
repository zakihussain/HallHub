# HallHub

HallHub is a static wedding venue discovery and booking website for Pakistan. It includes:

- Homepage search with dropdown filters
- Venue discovery and detailed hall pages
- Real venue locations, galleries, availability, catering and decoration options
- Booking, payment and downloadable confirmation flows
- Admin login and dashboard views

## Run locally

From this folder, start any static server, for example:

```powershell
python -m http.server 4173
```

Then open <http://localhost:4173>.

## Netlify

This is a client-side static site. Netlify can deploy the repository with the project root as the publish directory.
